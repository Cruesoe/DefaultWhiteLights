[b]Electric lights default to white instead of orange, with an optional color for each room type.[/b]

I never liked orange lights; I prefer white.

[h2]Features[/h2]
[list]
[*]Standing lamps, wall lamps, flood lights and other colorable electric lights default to white instead of orange.
[*]Each room type can have its own color, and a light built in that room uses it.
[*]Room types without a color of their own use the global default.
[*]The in-game color picker and the Ideology darklight toggle still work.
[*]Sun lamps, torches, campfires and other lights that can't be recolored in vanilla are left alone.
[/list]

[h2]Settings[/h2]
[list]
[*][b]All lights[/b]: the global default color.
[*][b]Room colors[/b]: tick a room type and click its color box to override the default for lights built there.
[*][b]Apply to all existing lights[/b]: recolors the lights already on the map to the current settings.
[/list]

[h2]Compatibility[/h2]
Safe to add to an existing save. Lights already built keep their color until you use Apply to all existing lights.
